# Builder reference

Every method on `TelnetInterpreterBuilder`, and every plugin setting reachable from the chain it
returns. A setting written after an `.AddPlugin<T>()` belongs to that plugin; everything in
[Interpreter](#interpreter) belongs to the connection and may be written anywhere in the chain.

This page is generated by hand from
[`TelnetInterpreterBuilder.cs`](../../TelnetNegotiationCore/Builders/TelnetInterpreterBuilder.cs) and
[`PluginConfigurationExtensions.cs`](../../TelnetNegotiationCore/Builders/PluginConfigurationExtensions.cs);
if something is missing here it is a bug in this page.

## Interpreter

| Method | What it does |
| --- | --- |
| `.UseMode(TelnetInterpreter.TelnetMode)` | `Server` or `Client`. Required. |
| `.UseLogger(ILogger)` | Where the interpreter and every plugin log. Resolved from DI when you use `AddTelnetServer()` / `AddTelnetClient()`. |
| `.OnSubmit((bytes, encoding, telnet) => …)` | A complete line of ordinary input. Required. |
| `.OnNegotiation(bytes => …)` | Where negotiation bytes are written. Set for you by `UsePipe`, `UseStream` and `BuildAndStartAsync`. |
| `.WithClientIdentity(ClientIdentity)` / `.WithClientIdentity(name, version)` | Who this application is — feeds TTYPE and NEW-ENVIRON together. See [Saying who your application is](../guides/client-identity.md). |
| `.WithMaxBufferSize(int)` | Longest line of ordinary input the interpreter will assemble. Default 5 MiB; a longer line is dropped whole, not truncated. See [Limits](../concepts/limits.md). |
| `.WithKeepAlive()` / `.WithKeepAlive(interval)` / `.WithKeepAlive(interval, payload)` | `IAC NOP` after a window of outbound silence. Off by default. See [Keep-alive](../guides/keep-alive.md). |
| `.UsePipe(IDuplexPipe)` / `.UseStream(Stream)` | Wire `OnNegotiation` to a transport and leave the read loop to you. See [Managing the read loop yourself](../guides/connection-management.md). |
| `.AddPlugin<T>()` | Register a protocol plugin and open its configuration chain. |
| `.AddPlugin(ITelnetProtocolPlugin)` | Register an instance you constructed yourself. |
| `.AddDefaultMUDProtocols(…)` | NAWS, GMCP, MSDP, MSSP, TTYPE, CHARSET, EOR, SUPPRESS-GO-AHEAD and MXP in one call — plus Packet Patch when given an `onPrompt`. Follow with `.OnTerminalTypes(types => …)` to configure TTYPE. |
| `.BuildAsync()` | The interpreter, with no read loop started. |
| `.BuildAndStartAsync(IDuplexPipe \| Stream \| TcpClient, ct)` | The interpreter and a `Task` that completes when the peer closes. |
| `TelnetInterpreterBuilder.ReadFromPipeAsync(telnet, reader, ct)` | The read loop on its own, for a connection built with `BuildAsync`. |
